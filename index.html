💡 Innovation

Smart Irrigation uses soil moisture information to help farmers provide water when crops need it. This can reduce unnecessary water usage, save time, and improve irrigation management.

In the future, this project can be connected to an ESP32, soil moisture sensor, relay module and water pump to create a real IoT-based irrigation system.
